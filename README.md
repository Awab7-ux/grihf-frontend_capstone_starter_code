# Medical Appointment Booking

StayHealthy - Go Digital initiative: a platform to book doctor appointments online.

## Setup Instructions
1. git clone https://github.com/Awab7-ux/grihf-frontend_capstone_starter_code.git
2. cd grihf-frontend_capstone_starter_code
3. npm install
4. npm run dev
5. Backend: cd backend && npm install && npm start
6. Production build: npm run build
